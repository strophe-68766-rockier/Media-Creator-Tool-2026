## FAQ

### What is VideoPatch?

VideoPatch is a Windows utility designed to unlock premium features in popular video editing software, removing watermarks and activating pro tools.

### Is VideoPatch safe to use?

Yes, VideoPatch is scanned for tool and does not contain any components. It modifies only the target application files, not your operating system.

### Which video editors are supported?

It currently supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi, with plans to add more in the future.

### Do I need to purchase the software first?

VideoPatch is designed to work with both trial and installed versions of the software to unlock features that require a premium license.

### Will this affect my existing projects?

No, the patching process is non-destructive to your project files. It only alters the application's executable and resource files.

### How do I know if the patch was successful?

After running VideoPatch, open your video editor and check for the absence of watermarks and the availability of premium export options.

### Is this a permanent unlock?

Yes, the patch applies a permanent modification to the software. It will remain active until you uninstall or update the application itself.

### Can I use this on a different computer?

Yes, but you must download and run VideoPatch on the specific computer where the video editing software is installed.
